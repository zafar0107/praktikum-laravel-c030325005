# Proyek Praktikum Pemrograman Web - Laravel

## Deskripsi Singkat
Proyek ini dikembangkan sebagai bagian dari rangkaian tugas praktikum mata kuliah Pemrograman Web menggunakan framework **Laravel 13**. Aplikasi ini mengimplementasikan konsep-konsep dasar pengembangan web modern meliputi *Routing*, *Blade Templating*, *Controller*, Pengelolaan Database SQLite, fungsi *CRUD* (Create, Read, Update, Delete), hingga sistem *Autentikasi*.

## Spesifikasi & Teknologi
- **Framework:** Laravel 13
- **Bahasa Pemrograman:** PHP 8.x
- **Database:** SQLite
- **Version Control:** Git & GitHub
